# Linux System Report Generator

This project generates a Linux system report using a Bash script.

## How to Use

1. Make script executable:
chmod +x system_report.sh

2. Run the script:
./system_report.sh

3. Output file will be created:
system-report.txt

## What it shows
- Hostname
- Kernel Version
- Disk Usage
- Memory Usage
- Top Running Processes
